Monochrome SVG Icon System - Demo

Professional icon system using SVG sprite with currentColor for CSS tinting.

Usage Methods

1. JavaScript Module (Recommended)

import { icon, injectSprite, initIcons } from './assets/icons/icons.js';

// Auto-initialize (injects sprite + replaces data-icon elements)
await initIcons();

// Or manually inject sprite once
await injectSprite();

// Create icon element
const svgEl = createIcon('arrow-right', { size: 'lg', ariaLabel: 'Next' });
element.appendChild(svgEl);

// Get HTML string for innerHTML
element.innerHTML = icon('github', { size: 'xl', class: 'icon-primary' });
